# Soporte

Antes de abrir un issue:

1. ejecuta `ani-es --version`;
2. confirma `bash --version`, `mpv --version` y `yt-dlp --version`;
3. reproduce con `ANI_ES_DEBUG=1`;
4. revisa si falla la variante, el servidor o el reproductor.

Al compartir logs, elimina el `WORKDIR` después de revisarlo y no publiques cookies, rutas personales ni URLs firmadas. `ani-es` redacta queries y fragmentos, pero conviene inspeccionar el texto manualmente.

Los cambios temporales de AnimeAV1 o de un host de video pueden resolverse sin modificar el programa. Indica la URL pública del anime y episodio, nunca una URL multimedia firmada.
